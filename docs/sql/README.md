# سجلّ تشغيل سكربتات القاعدة

**⚠️ هذا الملف موجود لأن التتبّع انزلق فعلًا:** قلتُ للمالك إن ٠٤٦ و٠٤٧ معلّقان
وكان قد شغّلهما، **وسأله هو الذي كشف الفارق لا فحصٌ عندنا**. والسبب بنيويّ لا
سهو: **حالة التشغيل تعيش عند المالك وحده، والمستودع لا يراها**، فأي ذاكرةٍ عنها
تتقادم بصمت.

**فالحالة تُكتب هنا لحظة تأكيد المالك، ولا تُستنتج من المحادثة.**

| # | ما يفعله | الحالة | الدليل الذي أكّده المالك |
|---|---|---|---|
| ٠٤٢ | مسبار `select … into` عند صفر صفوف | ✅ شُغّل | `null-assigned` |
| ٠٤٣ | عمود `cost_is_estimated` + الـview + الدوالّ الأربع + تصحيح أربعة صفوف | ✅ شُغّل | كل الفحوص طابقت المتوقَّع |
| ٠٤٤ | إرخاء `stock_documents_transfer_shape_check` | ✅ شُغّل | عكسُ التحويل نجح بعده |
| ٠٤٥ | فهرس تفرّد على `reverses_document_id` | ✅ شُغّل | الفحصان نجحا |
| ٠٤٦ | تصحيح وصف `cost_is_estimated` | ✅ شُغّل | `col_description` رجع النصّ المصحَّح حرفًا بحرف |
| ٠٤٧ | `supplier_doc_number` + توقيع `post_stock_document` | ✅ شُغّل | الفحوص الخمسة + مستند توريد حقيقي من الشاشة والأرصدة تحدّثت |

## ⚠️ ملاحظتان تخصّان التشغيل نفسه

**١. العربية داخل `$function$` قد لا تنجو.** شُغّل ٠٤٧ **بتعليقات إنجليزية**
تفاديًا لمشكلة تشفيرٍ وقعت مع ٠٤٣. والتعليقات لا تهمّ — **لكن `using hint = '…'`
عربيةٌ كذلك، وهي الدرجة الثانية بسلّم رسائل الخطأ وتصل شاشة المستخدم كما هي.**
وسكربت ٠٤٨ يقيس ذلك، **ونتيجته تشخيصية**: ستّ إشاراتٍ أُعيد إيداعها بـ٠٤٧
واثنتا عشرة ما زالت من ٠٤٣، فالقسمة تقول أيّ تشغيلٍ تأثّر.

**٢. كل نصٍّ عربيّ يُودَع بالقاعدة يُقرأ راجعًا بنفس السكربت.** ٠٤٦ فعلها
(الفحص ١ يقرأ `col_description`)، **وهي القاعدة لا الاستثناء**: ما يُشحن إلى
مكانٍ لا نراه يُقرأ منه.
